# Dev Portfolio OS

**A developer portfolio inside a VS Code-inspired workspace.**

**Project status:** In development

---

## 🇬🇧 English

### About the project

Dev Portfolio OS is my personal portfolio and a full-stack MERN project, designed to showcase my professional experience, technical skills, and web development projects.

The interface combines a Visual Studio Code-inspired environment with a modern dashboard layout powered by CSS Grid.

The goal is to create a memorable, responsive, and accessible experience while demonstrating practical frontend and backend development skills.

### Planned features

- Responsive, CSS Grid-based dashboard.
- IDE-inspired interface with interactive elements.
- Personal introduction, professional experience, and technical skills.
- Project gallery with descriptions, technologies, and links.
- Backend REST API for project management.
- MongoDB database for persistent project storage.
- Private administration dashboard with authentication and CRUD operations.
- Contact section and social links.

### Tech stack

- **Frontend:** React, JavaScript, HTML5, CSS3
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Version control:** Git and GitHub

### Project goals

This project is an opportunity to strengthen my MERN stack skills, improve my understanding of application architecture, and build a professional portfolio that reflects both my experience and my personality as a developer.
